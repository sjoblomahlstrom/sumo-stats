# Sumo Rankings & Statistics

A multilingual website for exploring professional sumo wrestling rankings, wrestler profiles, tournament results and statistics.

## Live Website

https://sjoblomahlstrom.github.io/sumo-stats/

## Features

- Rankings for all six professional sumo divisions
- Tournament selection and historical statistics
- Wrestler search and individual profiles
- Career statistics and tournament history
- Comparison of two sumo wrestlers
- Top 10 wrestler rankings
- Tournament calendar for 2026
- Live results section
- Swedish, English and Japanese language support
- NHK WORLD-JAPAN YouTube playlist
- Responsive design for desktop and mobile devices

## Technologies

- HTML5
- CSS3
- JavaScript
- JSON
- Python for data processing
- Git and GitHub
- GitHub Pages for hosting

## Data Sources

Sumo statistics are collected using the Sumo API.

https://www.sumo-api.com/

Official tournament information:

https://www.sumo.or.jp/En/

## Project Structure

- index.html - Main website
- style.css - Website design
- script.js - Main functionality
- live-results.js - Tournament results
- rikishi.json - Wrestler data
- rikishi-career-stats.json - Career statistics
- rikishi-extended.json - Extended wrestler information
- sumo-calendar.json - Tournament calendar
- tournaments/ - Tournament data
- images/ - Wrestler images
